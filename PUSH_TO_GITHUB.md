# Informasi Push ke GitHub

Isi informasi berikut jika ingin perubahan langsung saya push ke GitHub:

1. **URL repository GitHub:** `https://github.com/username/nama-repository.git`
2. **Branch yang digunakan:** `main`
3. **Commit message:** Ditentukan oleh AI berdasarkan perubahan yang dilakukan.

## Template

```text
1. URL repository GitHub: https://github.com/username/nama-repository.git
2. Branch mana yang di-push?: main
3. Commit message apa?: Sesuaikan dengan perubahan yang sudah dilakukan oleh AI
```

Setelah informasi di atas diberikan, AI dapat menentukan commit message yang sesuai, lalu mempersiapkan, meng-commit, dan me-push perubahan ke repository tersebut.
